# Exact reverse/add carrier in three planes

Scope: **retained bounded research design, not the current production constructor**. Its algebra and experiments remain useful; descriptions of execution below refer to that historical prototype. The current [reverse/add synthesis](../research/reverse-add.md) identifies the implemented owner and unresolved temporal grammar.

`FactoredReverseCarrier` stores a `TemporalCell` as three separately typed,
canonical grammar roots: domain, F5 value, and Boolean half. Source admission
may import pair coefficients. Successor execution uses only the three small
alphabets and never reconstructs a digit word or a 19-symbol pair field.

The scalar laws have one owner in `decimal_pair_coordinates.py`. For
`S = alpha + 5 beta + 10 nu`, the domain determines `nu`; EQ admits only
`(alpha,beta)=(4,1)`, and LT/GT exclude that combination. Source fields must
be symmetric and have an even middle coefficient when their width is odd.

The existing `program_word` owner supplies canonical counted leaves and
recursive concat grammars. Plane gates zip aligned grammar intervals, stop
on uniform intervals, and intern their outputs independently. All Python
traversals are iterative. A uniform interval's represented length is never
the iteration count of a successor operation.

The domain grammar supplies both carry-prefix inputs and final growth. Alpha
normalization uses addition in F5; beta normalization uses the wrap predicate.
The threshold, XOR, and majority gates then determine the next beta and
domain planes. Alpha transport is `2I` without growth or `I+S` with growth,
plus the reflected carry forcing. Right padding makes the growth edge part
of the same affine action.

## Temporal composition and equality

`FactoredTemporalPower` composes source-bound segments using an explicit
stack. Each segment retains an `F5AffineTransport`: a homogeneous descriptor
`2^q (I+S)^r` and an independently represented forcing plane. Composition
transports earlier forcing before adding later forcing. Earlier forcing and
the original source are padded to the final width before application.

The homogeneous descriptor uses the existing characteristic-five Frobenius
factorization. The temporal executor applies the cumulative descriptor when
combining segments and requires its alpha output to equal the independently
computed endpoint. This is powered F5 transport inside exact execution.
It does **not** eliminate primitive domain/Boolean evolution: its forcing is
source-bound, and unresolved nonlinear gates still require those steps.

`OutputResidualID` contains the three canonical **output** roots. Distinct
sources with identical interacted output planes therefore merge. Input
coordinates, event counts, source-bound affine descriptors, and histories
are not part of this output identity. This normal form currently gives exact
endpoint equality; no additional minimization of unequal endpoints is claimed.

## Scope and measurements

This is an endpoint construction API, with sorted owner-issued handles and
bounded transient gate work. It is not admitted to the public point-query
cache or substituted for `ReverseAddPoweredTerm`. Such admission still needs
the compiler's resource ownership and powered scaling certificates.

The proof driver reports each plane's grammar nodes and runs independently.
Its combined output-residual count counts unique aligned macrocell triples;
it does not materialize a combined alphabet, and it is not a count of a
certified finite temporal quotient. Node counts alone do not prove entropy
or asymptotic compression bounds.
