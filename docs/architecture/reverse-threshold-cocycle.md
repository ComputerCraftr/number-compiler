## Complete contextual temporal actions

`CocycleTemporalArena` composes complete finite interfaces. Every action
contains typed input ports, their simultaneous output functions, endpoint
cocycle residuals, and a common admissibility function. That common predicate
includes the definedness of every output, even when a later consumer ignores
one. Composition pulls back the later predicate and all outputs through the
earlier outputs, then normalizes. Intermediate values remain functions;
there is no loop over primitive generations or point evaluation.

The event count is diagnostic execution metadata, excluded from semantic
function equality. Equal extensional actions can represent different powers.
The input signature remains part of identity: the API does not infer absent
boundary/extent ports or prove that a caller's finite interface closes under
unbounded arithmetic growth.

The bounded reverse/add research compiler uses an explicit capacity and
variable width. Overflow is undefined, and this condition survives squaring.
It constructs an unbound function before a seed is supplied for indexed
oracle observation. This exposes the cost of retaining a complete finite
spatial context; it is not a recursive spatial context quotient. Its optional
reversal-orbit interface stores only the leading half of each symmetric
field, reconstructing logical inputs by shared width-conditioned aliases
before the carry functions are built. Odd centers require even parity. Both
interfaces retain extent and padding in their complete temporal contract.

There is an indexing requirement at growth. With normalized source digits
`D` extended by the new digit one, output i is `D[i] + D[m-i]`. The reflected
incoming carry must be retained. Replacing the second term by the forward
normalized `D[i-1]` is wrong: `(16,16)` normalizes to `(6,7)` and its growth
interior is `7+7=14`, not `7+6=13`.
