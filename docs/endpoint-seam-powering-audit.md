# Exact endpoint seams, depth germs, and temporal powering

The exact endpoint quotient is successor congruent. The new Isabelle proof
establishes this for every deterministic successor, including arbitrary future
durations and dyadic doubling. The bounded decimal and Collatz measurements
reproduce the supplied noninjective endpoint partitions. The F/M depth-germ

This completes the stated semantic seam laws. It does not complete a general

Existing public production guards and certificate admission remain unchanged.

## What is now proved

For any deterministic `F`, let `Q_N(x)=F^N(x)`. Isabelle proves

```text
Q_N(F(x)) = F(Q_N(x))
Q_N(x)=Q_N(y)  ==>  F^(N+M)(x)=F^(N+M)(y)
F^(2^(k+1))(x) = F^(2^k)(F^(2^k)(x)).
```

The endpoint projection is instantiated as an actual `temporal_quotient`, so
the generic successor premise is discharged rather than left as an assumption
about a proposed feature key. Determinism alone supplies this result once the
retained payload is the exact endpoint. It does not certify a smaller feature
summary as that endpoint or remove a demanded output such as physical ticks.

`Q_N` advances time. It is generally not an idempotent normalizer: applying it
twice advances `2N` steps. The new theorem does not substitute it for an
idempotent `NF` in the earlier normalization-at-every-seam theorem.

The five-theory `Temporal_Clock_Jumps` session also includes:

- Downward cylinder occupancy, one-hot mismatch curvature, and zero curvature
  across a completely matched radix-64 symbol.
- Rational normalized-cylinder composition and exact target-coordinate
  translation. A perturbation `2^k*h` of the source becomes `h` at the target,
  proving the normalized affine jet has slope one and no higher curvature.
- Minimum local depth owning the entire conjunction of survival observations,
  direct remaining-depth jumps, raw transverse first/second differences,
  Boolean readout first/second differences, and the canonical dead sink.
- The prior fixed-root/growth-phase, known-order, inverse-three lift and exact
  phase-truncation laws.

All theorem groups reject oracle dependencies. These are algebraic and
semantic specifications, not extracted proofs of all Python implementations.

## Fermat and Mersenne: derived depth/readout germs

The finite action coordinate is remaining depth `r`; the exact odd phase
remains occurrence payload. The raw signed coordinate `r=d+1-L` obeys
`r'=r-1`, first difference `-1`, and second difference zero. After death, the
published remaining coordinate is clipped to zero and all dead germs use one
canonical object. Clipping itself has a boundary pulse and must not be
confused with raw-coordinate curvature.

For `b=[r>0]`, the implemented readout differences are

```text
Δb  = -1 at r=1; zero elsewhere.
Δ²b = +1 at r=1, -1 at r=2; zero elsewhere.
```

They are computed from `r` and are not additional state fields. The full-carrier
probe reuses the independent Moore partition and counts the enriched observer

## Production growth and admission boundary

The production audit found no removable predecessor-germ field in
`PoweredResultKey`. Its action, input tile, ports, wiring, boundary operands,
fusion and region specify the demanded computation. Completed-result weights,
frame shifts and outgoing contracts are observable output semantics. They
cannot be dropped merely because two accelerated integer targets coincide.

Homogeneous field-action powers already omit child provenance from their
semantic identity. Complete endpoints and scoped result records also already
use canonical owners. Public reverse/add and Collatz terms create separate
compiler/ledger/index scopes, so this checkpoint does not create cross-term
cache hits by moving scoped IDs between owners.

There is one schema duplication: fused top-level bound ports repeat the fused
consumer contract and are validated equal. It does not create alternative
valid semantic keys. Removing the storage duplication would require a factory
and validator migration; it does not explain the measured endpoint conflicts
or supply the missing recursive evaluator.

F/M ordinary `nth` constructs sparse candidate numbers and bypasses HashLife.
Their classical Pépin/LL fallback still pays recurrence work. Symbolic binary
composition of a square action does not make its application logarithmic:
ordinary exponent evaluation sees a depth-sized exponent, and the trace
application runs the recurrence. A candidate-derived certified clock is still
needed before routing that fallback through the small depth action.
