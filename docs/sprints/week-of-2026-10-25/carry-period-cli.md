## Changes

Reverse/add uses one ordered carry projection for its reflected coefficient
oracle and admits bounded T16/T32 publications. Physical T2 work remains
chronological and is accounted separately. The mod-99 alternating accumulator
and innovation-matrix projection avoid constructing a Q19 endpoint.
The controlled mod-7 action retains supplied carry letters as a precondition.

2rev10 shares bounded causal halos across finite defect samples, joins the
four requested observations, and reuses an already issued complete endpoint
for the seed-morphism consumer. Its modular Laurent projection retains the
source admission and physical phase. The cone evaluator uses an iterative
semantic-tile worklist and batched accounting.

Collatz uses conservative candidate admission and displacement bounds before
speculative macro discovery. Exact double accumulators consume the existing
joint action. The finite repeated-word class preserves its exit guard;
completed transition validation does not repeat binary powering.

The registry owns the new observations. The existing `temporal.residue99`
name remains canonical; no removed alias was restored. Immutable stock
parser metadata is reused while each request receives a fresh namespace.

## Source-seam and resource audit

The reverse archive's residue-only affine join was not retained. Its unused
source-pointed projection API was deleted; production joins remain with the
existing Q19 owner and exact issued source seam. Equal widths and mod-7
residues do not authorize substituting another coefficient tape.

The 2rev10 Laurent observer now takes the live term owner, validates the
already-issued prefix cursor and its full source digits, and checks both
morphism roots against available issued endpoints. Regressions cover distinct
seeds whose trajectories merge, equal-width/mod-198 collisions, stale cursors
and forged roots. A merged trajectory does not authenticate the original
seed's accumulated sum.

The reverse accumulator admits its source size before reversal, reserves
scratch for the complete bounded bootstrap and records digit, operand and
failed work separately. Source and generation residues are produced inside
that guarded scope; the matrix consumer no longer multiplies the full
generation by the source reversal. Cancellation and exceptions release scratch.
The Collatz transition issuer rejects Boolean source aliases.

The three later Laurent reports were audited separately. The bounded reverse
mod-7/mod-198 consumer uses exact canonical half-tape seams and a ledger-owned
result memo; longer requests retain the existing exact Q19 fallback. Query
eviction causes recomputation rather than a stale hit or a new refusal. The
optional Laurent path also falls back after a typed scratch-capacity refusal;
the Q19 path still enforces its own budget and source duration. Authority
errors and cancellation are not caught as capacity misses. The
archive's unbudgeted cache and incompatible carry-action keyword were not
ported. The half-tape scan refinement is separately kernel-checked from the
accumulator algebra.

Literal checks exposed a one-step carry-port clock error: the port from
`x_n` to `x_(n+1)` determines the supplied modular action from `x_(n+1)` to
`x_(n+2)`. The final consumer removes the redundant scalar-action
reconstruction entirely: its output did not consume it. The half-tape
producer uses the existing shared mirrored-run pairing instead of another
copied loop. The 160-step literal differential test retains the
clock/action assertions, and also compares the old switch-derived J with the
direct residue formula. Production derives J from the forward/reversed
mod-693 projections already computed on the same exact tape. The mod-11 guard
and exact chronological seam remain mandatory.

The term memo seals each Laurent result to the exact source/action binding
and an opaque per-term token. Adversarial tests reject a same-type result or
wrapper copied from another term. Eviction clears the payload; disposal
rotates the token. Laurent work is reported by explicit nullable schema-eight
fields, including failed work and cache publication failures.

The 2rev10 source-word weight is the scalar decimal value of an authenticated
source SLP. Finite joins require exact adjacent roots; an entire powered
action cannot be treated as a single source weight. Trailing-zero contraction
can preserve a future endpoint while changing this weight, so that seam is
refused by the finite weight view and left to the existing exact path. These
scalar laws do not establish a polynomial-valued accumulator recurrence.
Its finite joined API now charges retained path, binding and authority records
to one caller-owned reservation. Joins require the same live scope; closing
that scope invalidates the view. Failed publication refunds its charge, and
modular evaluation releases temporary fold work without releasing the retained
path. The scalar view is not published as a full-polynomial CLI descriptor.

Antihydra's detailed and pointwise odd-seam observers authenticate the seam
once, then share the validated q-port projection. The duplicate public helper
was removed after its callers migrated. Forged-seam rejection remains covered;
this removes redundant observer work without asserting a new ordinary-term
constructor.

## Rejected approaches

The archive's recursive cone evaluator was replaced with an iterative
worklist. Duplicate binary-power loops use the existing shared arithmetic
owner. Large physical `(width, half-runs)` keys were not introduced as
semantic quotient IDs. Matching modular endpoints do not authenticate an
exact physical source seam. Publicly constructible weighted transition
records cannot grant unlimited future authority.

Finite period observations do not establish permanent interior carry
periodicity. Modular logarithmic powering is not a logarithmic full-word
output claim. No archive test-harness bypass or proof oracle is admitted.

## Adversarial authority and lifecycle follow-up

The follow-up audit separates reusable observer identities from exact source
and application authority. In the inspected comma constructors, theorem caches
remain local to the invocation/context; source admission precedes reuse of a
Near action row. The continuation graph is a conservative one-step signature,
not evidence of a minimal future quotient. This audit found no reason to remove
the pending B1/B32/global acceptance gates.

The unused three-coordinate mod-99 proof view has been replaced by the scalar
output class actually observed by that theory. One-step congruence and induction
now prove equality of all future scalar outputs, with the converse obtained at
time zero. Python's ordered pair/difference/phase packet retains its richer
identity. The removed phase-freeze and phase-merge claims had no external
consumers; their scalar-observer purpose is covered by the new exact future
observation equivalence. The registered `Reverse_Residuals` kernel rebuild
passes in 36 seconds (41 seconds including orchestration), receipt
`20261030T141101Z-3b66d5a9e85d4032acef6c950243ffc2`. Parent heaps were reused.

Runtime findings and repairs:

- Mahler fragments authenticate the complete ordered motif action at construction.
  Equal extent and event count do not authorize reusing a different ordered word.
  Reads check the retained binding rather than recomposing the word.
- Collatz boundary macros bind their issued coefficients, clocks, identity and
  blank payload. Equal endpoints cannot substitute a different accumulator sum.
  The weighted consumer reuses the selector-issued action instead of independently
  powering it again, subject to the same exact source and repetition checks.
- Decoded Collatz coefficient tuples no longer carry producer authority. Joint
  process-cache admission validates the bounded source word once and charges that
  validation; mixed-cache admission checks the complete motif-derived action.
  Typed query-local hits reuse the admitted action without repeating restoration.
  This is not a claim that cold process-cache promotion avoids reconstruction.
- Root publication retains the checked joint action in an existing ledger-owned
  memo and resolves scalar port payloads only against that retained action.
  Payload audits check the exact memo owner, endpoint, clock and issued fields.
  Disposal and failed construction release the retained payload.
- A warmed mixed-action memo now rechecks the requested minimum duration. A short
  hit falls through to the longer-candidate search instead of satisfying an
  incompatible request. Cache bypass disables this path; query-local reuse does
  not leak across requests.
- Reverse Laurent memo entries retain a complete result snapshot. Mutation of a
  same-generation result is rejected before hit accounting; source, generation,
  consumer and per-term authority checks remain in place.
- Temporary ledger reservations reconcile actual committed owner charges when
  reserve, release or transfer raises. Retrying cleanup cannot spend a neighboring
  reservation's credit. Double-reverse source-word cleanup uses the existing
  all-callback cleanup owner so one failure does not skip unrelated releases.

The finite scalar source-word cocycle remains an offline bounded API; it is not
wired to the polynomial-valued CLI accumulator. The Mahler source-program
compiler likewise does not establish a new main-executor speedup. These findings
are integration boundaries, not grounds to substitute inequivalent operators.
The audited reverse Laurent scratch owner is intentionally reused per live term;
creating and retiring a new owner on every demand would add lifecycle overhead.
The performance samples above precede this follow-up. Its avoided repeated
powering and restoration are covered by poison tests; no new end-to-end speedup
is inferred from hit counters or from the full-suite duration. Colima was not
running for this audit, so the new execution evidence is native macOS only.
