## Changes

A shared `BlankLedger` composes exact width displacement and minimum/maximum
prefix widths through the existing `PrefixSafety` algebra. Repetition uses
closed formulas and does not assert repeatability of the source action.
The independent retained-payload audit registers its geometry fields.
Collatz composes this summary while constructing existing exact runs and pinned
cycles. The source-image publication seals the summary; the optional clock
packet reads it without trajectory discovery. Demanded D8 prefixes derive
widths from bounded affine actions: first use builds a separately charged,
memoized eight-symbol prefix row. Exact width
summaries are cached by the complete source fiber; endpoint-only cylinder
transport does not transport these summaries. A missing summary remains `null`
instead of triggering replay. Ordinary endpoint requests skip this work.

Reverse/add uses the scheduler's authenticated cached-only projection lookup to
tighten `maximum_width` after a width demand. A missing projection falls back to
the existing conservative bound without construction. There is no additional
local projection cache or width-planning owner. The scheduler now returns a ledger-owned pair grammar
with Q19 width summaries and an exact output morphism. Point queries descend
region summaries; streaming traverses the spatial grammar once in each mirrored
half. The finite spatial law is immutable, including its resolver closure.

Primitive and relative-reuse candidate creation now share the same optional
adapter transaction through scheduler publication as composite candidates.
Injected publication failures roll back adapter records.

Mahler's exact one-bit action now has one production owner, also used by the
research predicate. The authenticated one-return path avoids a redundant
aggregate projection. No general Mahler temporal output-tape bridge is claimed.

## Rejected approaches

The Collatz archive's `compile_one_run_action` visits each odd source and
materializes its intermediate integer. Its transported-cache fallback also
replays normalized blocks to construct tape data. Those are not acceptable
width/clock fast paths. Summing exact blank widths and modular F5 outputs into
monotone work counters cannot provide authoritative result metadata.

The reverse patch's independent exact-width planner depends on an absent
archive owner and would create a second construction in this checkout. Exact
width must come from the existing admitted occurrence.

The Mahler report expressly leaves the live source-publication bridge open.
Its bounded golden-mean grammar is not a global Sturmian or source-repeatability
certificate. A Boolean caller override is not authenticated repeat admission.
