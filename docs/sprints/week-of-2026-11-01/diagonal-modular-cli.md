## Changes

Reverse/add transports modular endpoint and reflected-endpoint residues from
the same issued carry-switch intervals. Only the seed requires a complete
digit-run residue fold. The symmetric producer validates public runs once and
pairs its already normalized internal runs directly. The mod-99 rank-one
action powers arbitrary admitted coefficients by exact division after a
mod-297 power. Its bounded, evictable term memo is ledger-owned; base and
optional source-reversal projections preserve demand order and scratch cleanup.
Cached nested state/action snapshots retain detached scalar fields, so mutation
cannot change both the saved and live value. Valid warm hits do not reconstruct
those actions. Optional Laurent memo capacity refusal releases its reservation
and returns the already computed result; other publication failures propagate
after cleanup.

The 2rev10 seed-morphism consumer reuses its completed scheduler endpoint.
Modulo-990, doubled-digit modulo-90, and the lowest borrow projection use the
same admitted mod-198 and physical-phase clock. They grant no full borrow-mask
period or unrestricted source closure. The proposed flat frame stack and
packed pair keys were rejected after measurements showed an ordinary-query
regression; the original iterative frames and local tuple keys remain.

Collatz's bounded low-bit producer issues an endpoint action and exact
physical/normalized clocks. Successor-sum and predecessor fields are retained
only for consumers that demand them; ordinary values avoid that arithmetic. The executor consumes that action before
repeated small fallback work on eligible sources. An explicitly requested
innovation grammar consumes its same-pass parity mask; it does not rediscover
that word. Named/cached admission, pending odd half-steps, source guards and
reset boundaries remain distinct. This is finite source discovery, not an
unrestricted logarithmic parity oracle.

The same producer pass retains aligned dyadic boundary snapshots so the
existing occurrence cache can join real adjacent segments and transport them
to compatible receiving seeds. Catalogue candidate presence does not veto an
independently admitted window; completed cached actions and terminal powers
are still offered first. Window iterations contribute to the shared primitive
work counter, with endpoint and prefix-validation operand work counted
separately. Optional parity-mask shifts and ORs also charge their operand work.
After consuming aligned prefixes, the executor advances its source/width/ones
cursor, preventing the next loop from publishing the same span a second time.
A large-source regression checks exact endpoints and warm reuse on a compatible
receiving seed. Two cache tests now compare this complete source-discovery measure
instead of D8-only work or the number of batched actions; their endpoint,
transported-parent, admission and resource assertions remain intact.

The demanded Collatz diagonal packet reuses that joint action. Its field uses
shared normalization and polynomial division; sparse moving-cut reflection
has one shared arithmetic owner. The aggregate A/B Laurent defect is distinct
from a sum of historical carries. Zero and unit polynomial division were
repaired in the shared owner after the zero-step CLI fixture exposed them.
Ordinary values, metadata, metrics and temporal summaries do not build these
spatial fields.

The existing [Antihydra carry integration](antihydra-carry-morphism.md) remains
the source-bound X15 owner. The new archive's alternate chunked constructor
does not establish a cold improvement over the balanced producer and is not
installed as a second scheduler. Its physical correction, centered innovation,
moving cut and safety authority remain separate. No new general Antihydra cold
speedup is claimed by this follow-up.

## Finite ordinary nth follow-up

The subsequent November 1 inputs replace repeated intermediate publication on
bounded exact paths. Reverse/add admits every duration from 16 through 1,024,
including odd durations, while retaining its original bootstrap. It normalizes
the issued Q19 source once, performs the remaining exact decimal transitions in
a local context that traps rounding, and publishes only the final symmetric
half-tape. Its width guard is 20,000 digits; the existing run-level constructor
remains the exact fallback. Native ticks and digit visits are charged even
when execution fails. This is finite chronological arithmetic, not a new
logarithmic whole-word quotient.

2rev10 keeps the issued HashLife action and checks its exact source, duration
and incoming phase before consuming its endpoint. Bounded cones decode four
digit predicates once per row and obtain neighboring lanes by shifts. Scratch
is reserved before packing; a prepublication capacity miss can use the existing
semantic cone, while publication failures roll back and propagate. Packed rows
are measured separately from semantic-cache hits. The bit-work charge is a
conservative logical operand-width bound, not allocated bytes or elapsed time.

The archive's older scalar scheduler bypass and unused mirrored/Laurent observer
owners were not installed. Existing ordered accumulator consumers retain their
source and carry-history requirements; an endpoint projection cannot replace
those histories.

output, normal interpreter startup, and the existing guarded harness. Standard
