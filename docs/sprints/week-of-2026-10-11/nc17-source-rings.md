Period: 2026-10-11 through 2026-10-17 (Sunday–Saturday).

## Objective

Integrate the downloaded NC17 source-ring repairs through existing family
owners, sharing exact cylinder transport and preserving source authority.
Distinguish exact temporal composition from a proved discovery speedup.

## Changes

The shared integer-cylinder owner intersects bounded progressions using the
existing generalized CRT owner. Increasing affine transport preserves the full
stride and cardinality; multiplying a source modulus by three cannot be replaced
by a residue-only projection that silently enlarges the source fiber.
The shared Isabelle progression theorem supplies the corresponding image and
cardinality facts.

Reverse/add uses the existing Q19 numeric-port algebra for correlated carry and
outer/inner residues. Its `temporal.seed-orbit` observation exposes actual-root
composition and the number of bounded Q19 blocks performed. The implementation
still performs bounded T2/T4 blocks; it does not establish logarithmic discovery.

2rev10 publishes the actual intermediate SLP root during temporal composition.
Its `temporal.seed-morphism` observation accepts bounded source entry discovery
and optional finite center-window samples. Sampled returns never authorize an
infinite period. Help, metrics and ordinary queries do not request those samples.

Mahler source fibers retain fractional positivity and ledger prefix safety as
separate components. Collatz rooted actions consume admitted source quotients.
Fermat source-level squares preserve exact exponent-root adjacency, while
unknown interior carry histograms remain unresolved.

The adversarial review removed an unowned weak registry from the Q19 owner;
issued morphisms now reject copies through a self-weakref certificate and
validate their live owner occurrences. Mahler identity transport checks its
odd-source guard, including strengthened singleton cylinders, and precision
requests are bounded before exponentiation or ledger charging. Collatz pending
odd half-steps require odd input, absent digits are recognized before building
large radix powers, and disposal releases retained joint-action snapshots.
Collatz boundary publication now seals the selected macro instance and its
actual source-relative tick, including an internal prefix in a reentered chain.
Copied stamps, mutated macro bindings and Boolean integer aliases are rejected.

Repeated reverse seed-orbit demands reuse ledger-owned word-fiber projections;
their DAG and interval visits are counted at the traversal sites. Cache hits
validate the issued occurrence and immutable projection before returning it.
Fermat carry-ingress requests no longer rebuild signed phase histories at each
boundary, and terminal-status readout consumes the already authenticated
complete histograms with the original enumeration/work limits.

The reverse constraint propagator no longer runs a weaker symmetric-transfer
filter immediately before the stronger carry-aware filter. It decodes invariant
digit/carry domains outside nested candidate loops and reuses a middle projection
only while its exact domains and transfer maps match. Endpoint carry masks are
still joined on every application.

The October 17 integration-repair pass moves Boolean relation composition and
binary powering into a shared arithmetic owner. Collatz now checks cheap
negative admission before constructing a conditional graph, retains query-owned
positive and negative admission results, and constructs decimal/F5 matrix
observations only on demand. Positive memo reuse retains source and operand-size
checks. Mahler filters impossible odd-program suffixes before exact construction
and retains admitted motif actions rather than rebuilding them for point reads.

Reverse carry-word batch reads validate their live chain once per batch. Nested
2rev10 center samples use one shared pointed window per sample. Explicit CLI
matrix options consume the retained reverse carry bank, prepared 2rev10 source,
or issued Mahler source. Ordinary output and Mahler observations do not request
these matrices or the optional two-sided source-cylinder expansion. Registry
observation records are built by named fields, avoiding positional option drift.

The new reverse matrix remains a projected-domain overapproximation: its exact
punctured mod-99/mod-198 source-assignment join is not implemented. It cannot
authorize autonomous temporal repetition. The source-conditioned 2rev10 window
is bounded to four prepared F-steps; the Mahler window is bounded to 32 physical
ticks. Issuance, stale owners, Boolean/integer aliases, canceled publication and

successor generation or decimal conversion. A caller-built odd program can
produce a checked finite arithmetic trace, but its packet no longer claims
