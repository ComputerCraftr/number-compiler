Period: 2026-10-11 through 2026-10-17 (Sunday–Saturday).

[Week index](README.md)

## Objective

Integrate the downloaded finite carry-safety and Boolean-counter improvements
through existing source owners. Share arithmetic instead of duplicating family
observers, and bring the complete default Python unit run below 300 seconds.
Finite source constraints must not become an unsupported global future or
primality certificate.

The independent reachable-profile audit now reads each joint Boolean cofactor
once per audit, while continuing to check every input cube against the complete
certificate. Its memo is audit-local, so the next audit rereads mutated nodes.
The comma certificate checker determines decimal scale once for its nine
consecutive literal candidates; it still checks every candidate and decade seam.

Four test modules exercise development-only constructors rather than the

and parameterized cases remain available through explicit guarded selections.
No production cache-mutation, lifecycle, exact-output or P0 assertion was removed.

Fifteen additional modules that exclusively exercise research constructors or
verification-only quotient audits now live under `tests/validation/research`.
Their cases and assertions are retained. The default unit runner avoids importing
that already-excluded directory; explicit validation selections remain available.
The reverse-port predicate oracle computes each transfer image once, and the
temporal/radix test matrices share local source setup while checking every original
combination. No test runtime is shared between test cases.

The exhaustive 9,000-edge double-reversal audit now constructs its graph once,
instead of once per entry. It and the unchanged literal trajectory audit live in
`tests/validation/research/test_double_reverse_global_border_safety.py`.
The demanded CLI safety observation uses source-issued local carry constraints;
it does not build that global audit graph.

The shared binary carry action composes fold and Walsh summaries without
materializing concatenated output words. Radial and adaptive consumers use the
existing shared growth evaluator and Walsh coordinate transport. Collatz retries
its guarded selector at later authenticated source seams. Mahler's detailed
radix observation derives the Boolean successor window from its admitted action.

Collatz preserves its initial unified selector and existing parent-cache lookups.
Later discovery waits for the root dyadic checkpoint when ordinary shared-cache
construction needs that checkpoint for reuse. This repairs the integration that
had displaced parent publication; detailed observers still use their admitted
source seams. Poison tests target the module that actually owns the selector.

## Rejected approaches

A supplied-block carry action does not predict an unobserved future block.
Compatible border or width constraints do not authenticate a proposed source
trajectory. Leading Sturmian and low dyadic windows leave unknown interior
positions unless their authenticated intervals cover the complete source.
Neither CRT labels nor Walsh projections may fill those gaps with guessed bits.

Audit-local cofactor reuse must not persist across fresh audits, where frozen
objects may have been mutated deliberately. Relocating research tests does not
make their proof obligations disappear or turn a production refusal into a pass.
