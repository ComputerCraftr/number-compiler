# Continuation cleanup and growth attribution

The [CLI and clock-cylinder follow-up](cli-clock-cylinder-cleanup.md) adds the
128-phase lookup, direct text lowering, broad decimal audit and bounded
terminal deck checks. It records the remaining physical cache growth separately.

The [subsequent clock audit](clock-quotient-growth-audit.md) adds minimal-phase
action IDs, square-tangent lifetime controls and public cold/warm cache

port/boundary/input omissions have explicit observed output conflicts.

This follow-up implements demand-directed consumer pullback and audits the
remaining growth at the actual normalization boundaries. It does not infer
free-action equality from a bound trajectory or from identical local schemas.

## Implemented changes

`ReverseGeometryContext.project` selects requested output functions before
substitution; `pullback` composes only those functions and their admission
predicate. Full action composition uses the same owner. Midpoint variables
are substituted immediately, as they already were in full composition.

Substitution now resolves a selector first. If the replacement makes it
constant, the unchosen child is neither visited nor rebuilt. The indexed
research evaluator follows the same demand rule and counts only executed
nodes/tables. Its exhaustive validation therefore avoids evaluating other
widths and the unchosen growth branch at every source. Both implementations
use explicit stacks.

Consumer construction is transactional. A failed substitution discards
unpublished nodes and schemas and restores both interning maps. Existing
handles survive; work and discarded-allocation counters remain charged.
An A64 budget failure now leaves the valid A32 arena at 28,690 nodes instead
of filling it with the failed partial construction. Budgets are unchanged.

Collatz adds a symbolic directional consumer selected by free carry and root
shift. It emits two actions in the shared eight-element ternary action
alphabet, without publishing an exact normalized midpoint digit. The small
primitive response rows are constructed transiently on demand: no permanent
1,152-pair all-context table is retained. Growth depends only on carry and
shift. The exact root occurrence remains available to the root program.

The Fermat/Mersenne audit now checks binary multiplication congruence rather
than only one-step successor agreement. It uses the existing finite-observer
refinement owner, records distinguishing multiplication contexts, checks
addition separately, and refuses oversized Cartesian tables before allocation.

All stable results reconstruct their carrier. No noninjective `mulQ` or

M11, and M13 tables at 4,198,401, 1,048,576, and 16,777,216 cells respectively.
Those larger cases have preflight results, not completed refinements.

Addition fails even before consumer refinement. Independent sign/orbit
choices lose the relative phase required when combining child products.
Consequently a well-defined multiplicative quotient alone cannot justify
`A0^2 + 2*z^m*A0*A1 + z^(2m)*A1^2` on these carrier IDs. The remaining
block-combination target is the relative boundary action visible to addition
and folding. Terminal prime-bit factorization is a separate obligation.

## Production integration after the call-site audit

The public CLI/API paths use `ReverseAddPoweredTerm` and
`PoweredCollatzTerm`, then `HashLifeBlockIndex` and `TileScheduler`. The
research expression arena and accelerated radix64 event pipeline above are
separate executors. Their operation counts must not be attributed to public
nth-term execution.

The 196 causal primitive-pair transfer now requests a directional future
carry consumer on its right side. Producer geometry first chooses the
normalization/growth operands. The shared mod9 skew law consumes each operand
as a digit view, and a threshold comparison emits only a carry-monoid action.
Spatial composition interns the resulting forward/backward actions without
an exact pair output ID or the left edge's value payload. Distinct future
values such as the uniform 2 and 4 pair outputs therefore share this demanded
right action. Left consumers retain the edge value they actually need for
future growth. The production and proof experiment now import the same skew
arithmetic owner.

This is wired into causal transfer at future primitive-pair edges, including
within the public N=16/32 powered paths. It does not claim closure for every
composite temporal consumer. The exhaustive local regression checks all
20×43×5 producer contexts and every right consumer state while exact output
binding/emission is poisoned. Resource auditing independently checks the
retained directional summaries against exact output arithmetic and rejects
forged summaries.

Physical Collatz now compiles its leaf output from a one-sided branch/carry
consumer. Only the even division branch requests the right-neighbour value;
the odd branch uses its left carry state. The physical effect owns this law,
and the compiler publishes a reduced selector of the two directional
functions instead of building a joint 6×3 output table. Future composed tile
interfaces start from those functions. This uses the physical binary model;
an accelerated Hensel residual shift is not a port of that model.

Fermat/Mersenne retain exact coefficient-ring values for local products and
folding. Their shared square kernel now visits unordered coefficient pairs,
doubles off-diagonal products, and uses three recursive subsquares. No
general multiplication call is needed by that square implementation. The
outer sign/square quotient still kills information only after its consumer
permits it. See [the square-only follow-up](research/power-numbers/square-consumer-congruence.md).
The earlier binary multiplication/addition counterexamples apply to a
consumer requiring those operations; they do not reject a unary LL/Pépin
quotient. The full finite-ring unary audit tests that separate obligation.

These changes do not install an arbitrary-horizon free residual theorem or a
Fermat/Mersenne primality certificate in `TileScheduler`. The latter family's
bounded digit path benefits from the shared square kernel; its unresolved
large-candidate fallback remains the native classical backend.

boundary contexts still require discovering that result. Equal bound outputs
do not prove equal responses for all future consumers.

The concrete fan-out occurs in `TileScheduler._complete_direct`: a complete
parent requires both child contexts, recursively completed siblings, and a
joined parent publication. The point observer follows one coordinate, but
its causal boundary dependencies can request those complete spatial results.
The safe next normalization boundary is the demanded boundary function before
that completion. Deleting the sibling request from a complete-output task
would break its contract.

All six rows report zero sequential generation advances, retired interpreter
work, and explicit digit lowering. Query eviction is explicit; this run is
not an automatic eviction/recreation loop. Full CLI numeral output separately
uses `endpoint_lowering.iter_canonical_endpoint_digits`, which visits emitted
digits and charges the lowering counters. Neither compact action construction
nor a successful single-digit query removes that output-size cost.

The probes now report current scheduler counters directly. Legacy
`temporal_leaf_applications` is an alias of finite scheduler function work,
and `spacetime_macro_cache_entries` is an alias of the completed-result memo.
Neither means that a retired interpreter returned. The probes retain the
zero-replay checks and measured growth gates; they now test actual temporal
action publication and result retention instead of requiring retired image
publication counters to become nonzero.

For Fermat/Mersenne the remaining digit-backend costs are recursive coefficient
products, cross-term additions, cyclic/negacyclic folding, and scalar
end-around normalization for each square. The triangular kernel reduces
spatial work without reducing the number of nonlinear recurrence generations.
Lucas–Lehmer still executes its successive square-minus-two steps; the current
Pépin/digit path likewise does not supply a universal powered consumer
certificate. CLI `nth fermat` and `nth mersenne` denote the numbers themselves,
not their primality bits, and use their direct formula representations.

### Power-family width and unary-refinement results

On the complete residue rings, the square-only consumer partitions stabilize
at 9/129/16/64 classes for F2/F3/M5/M7, exactly their sign-class counts.
The initial partitions are 9/95/15/52. All sign and successor-congruence checks
pass, but these joint demanded observers have not produced additional stable
merging beyond sign. F3's full 257-state ring here differs from the 17-state
radix-orbit carrier in the binary audit; comparing their class totals directly
would be misleading.

An actual `ArithmeticTile` width probe also exposes the still-growing local
arithmetic. For the fixed source bit pattern `i mod 3 != 0`, the maximum
absolute folded coefficient at widths 8/16/32/64/128/256 is
3/6/11/22/43/86 in both families. At width 256 the observed carry interval is
−49…49 for Fermat and 12…49 for Mersenne. The implementation still constructs
a width-sized folded field before normalization. It does not yet implement
normalization after every bounded cross-product contribution. No fixed
finite `SquareCarryDomain` alphabet follows from the triangular work saving.

The final public N32 counters confirm that the new integrations execute:
196 evaluates 130 directional leaf consumers and interns 18 directional
compositions; Collatz compiles three factored physical output functions.
Their retained result-entry counts remain unchanged by these local
optimizations. A reduction in local construction should therefore not be
reported as closure of the boundary-occurrence population.
