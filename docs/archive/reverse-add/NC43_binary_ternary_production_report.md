# NC43 binary and ternary reverse/add source cutover

## Baseline and scope

Baseline: `NC43_guarded_moore_production_source.zip`. The legacy nondecimal completed-child evaluator refused requests beyond 128 generations. The actual source image adapter now issues either a compact certified binary phase or an immutable generic small-radix endpoint. The same issued image supplies width, digits, output streams, and the new `ReverseAddPoweredTerm.modular_residue(modulus)` API. The existing decimal Q19 and multiplier executors remain unchanged. Small nondecimal requests without a direct binary certificate (through 128 ticks) retain their existing exact path for compatibility; this is no longer the limit on production binary/ternary execution.

## Binary phase authority and proof

For seed 22 let n=4k+r, t=2^k. For k>=2 the exact source and width-aligned binary reversal are:

|r|source|reversed|
|---|---|---|
|0|48t²−6t|24t−3|
|1|48t²+18t−3|48t²−30t+3|
|2|96t²−12t|24t−3|
|3|96t²+12t−3|96t²−24t+3|

The four MSD-first run templates are `10 1^(k+1) 01 0^(k+1)`, `11 0^(k-1) 1 000 1^(k-1) 01`, `10 1^(k+1) 01 0^(k+2)`, `11 0^(k+1) 10 1^k 01`. Every run is positive. Geometric sums of these templates give the source/reversal expressions. Adding the two expressions takes each row to the next, with t replaced by 2t at the fourth return. Thus the grammar is closed, not an interpolation of sampled integer values. Width is 2k+6+(r>=2). The exact entry identities T^8(22)=744 and T^21(1)=48960=the phase (k=5,r=0) have independent scalar tests. For any other exact member, the run grammar recognizes the source directly. A short unknown binary input (<=256 bits) may use a fixed maximum 64 charged physical updates to establish entry; on failure the already-advanced endpoint is passed to the packed executor. No occurrence-index history is replayed or retained. For example seed 196 joins after six physical updates. The geometric run parameter is source data, not temporal fuel. Generation lengths remain in the existing scheduler binding, not the modular semantic ID.

`BinaryMooreAction` carries the exact modular nine-port observations (source, reflected source, overlap, two directed differences, XOR on/off between current and next source, carry mask, successor), together with carry phase p. The physical grammar induces (u,v,w)=(2t,16t²,0) in phases 0/1 or (0,32t²,4t) in phases 2/3. The one-step action is F(0,u,v,w)=(1,u,v,w), F(1,u,v,w)=(0,w,2v,2u). Four steps multiply the coordinates by (2,4,2). A jump computes modular powers and at most two residual half-returns. For the stated nine-port plus carry observation, minimality holds even for composite moduli: the phase-one coefficient matrix has integer 3x3 minors 207 and 4 (rows zero-indexed 0,1,5 and 2,6,7 respectively), whose gcd is one. A vector in the kernel modulo m is annihilated by both determinants, hence is zero. At phase zero one step exposes the same coordinates in phase one. Different carry phases are distinguished immediately. This does not claim minimality for source residue alone, nor a universal right congruence for arbitrary binary trajectories.

## General packed Q3/Q5 execution

Each uint64_t word processes 64 columns on one binary bitplane or two ternary digit bitplanes. Exact reflected words are fetched from opposite aligned lanes. Generate G and propagate E are disjoint. Put A=G|E and V=A+G+inlet; the incoming carry mask is (V xor A xor G)&active_mask, with overflow giving the outgoing carry. No scalar carry sweep or dense conditional table is used. Binary emits E xor C. Ternary one-hot input planes determine E, G and residue-one R1; R0 is the active complement of R1|E. Output planes are (R1 & ~C)|(R0 & C) and (E & ~C)|(R1 & C). The physical border emits a leading one on carry overflow; partial words and both alignments are tested. The Python portable fallback uses the same identities over packed integers (linear limbs), rather than a Python loop per digit per tick. Native output is converted to bytes only at publication. No intermediate rows are retained. Physical rows, native word tiles, portable word equivalents, full-word columns, births, and powered publications have distinct counters. Output allocations are charged and published within the scratch reservation; retained immutable output bytes or phase geometry are separately charged to the source-owned memo. The workspace ownership audit checks the new store, and disposal returns ledger nodes and entries to zero. Zero is a fixed-point action.

Generic admission is finite: at most 1,000,000 physical ticks, source width plus remaining ticks <=4,000,000, and conservative remaining word work <=200,000,000. This cap is separate from certified binary powering. The generic kernel has temporal height one and cost O(sum_t ceil(width_t/64)) on a 64-bit implementation; it does not establish a second temporal logarithmic factor, universal binary phase admission, or arbitrary ternary polynomial closure. Certified binary width/digit queries need only geometric arithmetic, and modular queries use O(log n) modular arithmetic operations. Materialized digits require output-sized work. The generic source-owned endpoint is not a universal temporal Hashlife action ID. Other radices are unchanged. No claim of Isabelle proof or ARM performance is made.

## Actual evidence

Build with `NUMBER_COMPILER_BUILD_NATIVE_REVERSE=1 python setup.py build_ext --inplace`. The source archive contains no binary build product. The isolated tests are reproducible with `PYTHONPATH=src:. python -m pytest -q --noconftest -o addopts='' tests/sequences/reverse_add/test_nc43_small_radix.py`. The guarded release command is separately attempted and fails at Git provenance (source ZIP has no .git), not claimed as release acceptance. New suite: 19 passed, including 840 random physical plane comparisons, 396 exact phase transitions, 3168 modular nine-port comparisons and compositions, 36 long owner fixtures, portable fallback and budget refusal. Existing regression selection: 98 passed; completed-scheduler regressions: 24 passed (43 including repeated 19 new tests). Independent C++ UBSan scalar comparison: 4000 randomized cases. Both CLI requests for 1000 ticks with base 2 seed22 and base3 seed196 succeeded with metrics. See `production_queries.txt` for huge binary point queries and counters. A certified huge query uses no generic executor; the regression deliberately forbids its execution. Native benchmark is three-trial median against an independent scalar C++ digit addition oracle, both including input/output conversion and endpoint comparison outside timing. It is not a measured speedup against an older NC43 executable, which rejected these long source requests. Benchmark is compiled with `g++ -std=c++20 -O3 -I src/number_compiler/kernels/native_reverse benchmark.cpp`. UBSan test with `g++ -std=c++20 -O2 -fsanitize=undefined -fno-sanitize-recover=all -I src/number_compiler/kernels/native_reverse ubsan.cpp`.
