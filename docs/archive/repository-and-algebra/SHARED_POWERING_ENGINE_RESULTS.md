# v0.59.9 shared powering-engine results

Reverse/add and physical Collatz share one production contract:

1. construct a source-independent temporal operator by binary composition;
2. represent the source and blank exterior as canonical aligned dyadic tiles;
3. apply high temporal children to whole spatial tiles through the joint spacetime cache;
4. return canonical future tile IDs and bounded interfaces, never an execution-history word;
5. descend only the requested point (or emit the requested full output when materialization is explicitly requested).

`BinaryLiftEngine` and older whole-state causal engines remain valid research tools for proved state quotients, but they are not public nth-state backends.

The remaining asymptotic frontier is minimization of the exact semantic/interface macrocell population, not removal of another sequential fallback.
