# Auxiliary powered monoids — condensed summary

## Collatz

- A known finite Collatz branch program is one exact dyadic-affine partial map.
- Binary composition powers that known program cheaply; it does **not** discover the future branch itinerary.
- Valuation/parity runs are the useful temporal coordinate, and current cleanup represents one valuation as one event rather than many `E/O` symbols.

## Primes

- Multiplicative factor-set state and additive translation form reusable finite wheel/product operators.
- Count/first prime-block summaries are constant-size observers even when projection work is not.
- Compact summaries must not be confused with compact projector construction.

## Cross-domain transfer

- Reuse one monoid/power implementation for predictable algebra.
- Keep hidden branch/support/event acquisition as a separate observer/injector problem.
- Reverse/add, Collatz, prime, and special-number experiments all follow the same rule: power the canonical transition, pull back constraints, and minimize only proved observer-equivalent state.
