
The width-indexed dyadic partitions supply both `L_e` at radix `2**(6-e)`
and `R_e` at radix `2**e`. Opposite orientations literally reuse the same

the next domain is the composition `R_e ∘ L_e`; its compiler does not need
to reconstruct a joined radix-64 digit. The exact output consumer retains

## Fermat and Mersenne: demanded boundary consumers

The shared square tile now exposes a demanded `RadixCarryAction` from its
actual folded product. Existing carry/cyclotomic transducers provide harmonic
consumer actions. Neither view becomes another stored tile coordinate. The
native recurrence, sign quotient, cyclic/negacyclic boundary, and exact
normalization remain owned by the shared arithmetic implementation.

An important negative control is exact carry plus payload. For any fixed
admitted port c and radix block b, the response
`(floor((u+c)/b), (u+c) mod b)` reconstructs `u`. It is injective and cannot
be presented as a noninjective action quotient. Carry-only and demanded
harmonic responses can merge products; their successor conflicts must still
be measured. The finite F3/F4/M7/M11/M13 audit does that separately from
terminal prime-bit observation and scheduler admission.

These are the existing bounded proof carriers, not every raw residue of each
candidate modulus. Harmonic rows use order four and coefficient modulus two.
The conflict counter counts source rows whose terminal-output/successor-class
signature differs from the first row in its class; it is not a count of
conflicted classes. A refinement can therefore increase this counter, as in
M13. Every row remains nonclosed. Products, harmonic emissions, and admitted
carry intervals are derived from the same sign-normalized tile convention;
the independent scalar recurrence checks every target.

Shared boundary-consumer machinery does not make the squaring map affine or
give it the Collatz inverse-three root clock. No new finite temporal family
certificate is issued. See [shared square arithmetic](architecture/arithmetic-square-tiles.md).
