## Reverse integration and rejected cold-path regression

A constant-size bound output summary composes the directed carry functions of an
executed producer occurrence and can answer a primitive reverse or digit-normalizer
consumer without exact output construction for that dependency. It is not a
successor-closed class for an arbitrary composite consumer. Independent review
identified and assigned request-bound publication, independent inventory and warm
exact-producer reuse corrections before acceptance.

The unrestricted cold deep-summary route was measured and rejected. At N=32,
it used **169,794 scheduler frames and 10.08 seconds**, compared with **44,692
frames and 4.30 seconds** when only that shortcut was disabled in the same tree.
It retained 884 tiles versus 977, but that small reduction concealed substantially
more interface work. Only one dependency, representing 63 cells, was discharged.
The comparison preserves both complete raw ledger counter maps. These are single
diagnostic trials, not a timing distribution or asymptotic proof.

Production admission must therefore keep bounded primitive-pair producers and
already prepared summary/completed-tile reuse, while declining cold deep summary
construction until it has a parent-first algorithm. The fallback is the existing
canonical causal-tile scheduler, not a generation loop or a second executor.
Explicit summary construction remains a correctness tool; it is not relabeled a
successful deep cold optimization.

The F5/F2 primitive laws and carry-derived forcing already execute. General
Frobenius temporal discharge must still connect those effects to pending deep
dependencies; a source-death plan alone is not counted as avoided execution.
Likewise, unequal directed reverse port domains require a proper conjugating
certificate before whole-request reflection can be admitted. The existing
same-machine symmetry check cannot simply be bypassed or called full D4.

Fermat/Mersenne ordinary output is already closed-form. General terminal quotient
extraction remains unproved in the retained research. Negative/injective candidate
tests were preserved; cleanup does not turn UNKNOWN into a primality result.
