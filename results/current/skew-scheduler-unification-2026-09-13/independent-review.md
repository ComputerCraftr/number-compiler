# Independent review scope

The final authored source is identified in `final-freeze.json`. Reviews below
are scoped code and mathematical reviews, not a substitute for executable
refinement or a declaration that all family migrations are complete.

| Review | Finding and disposition |
|---|---|
| Prime construction | The first shared-core path merely delegated to the old count wrapper. It was replaced by an actual fresh-prime filter image. A CLI test disables that wrapper and observes primitive filter applications. |
| Source publication | Frozen objects can still be changed through reflection. Publication seals now retain independent structural anchors, and their authority is outside the mutable records being checked. Registry storage and seal work are ledger-accounted. |
| Prime admission | Equal-looking foreign rank/factor-store owners were not excluded by constant-time stage validation. Original rank, ledger and append-only factor-store identities are now bound explicitly. Cached stage reuse also preserves exact integer input validation. |
| Prime resource admission | Adapter validation was initially counted separately without consuming the request work limit. It now consumes that limit. State admission includes source-image and seal records. |
| Prime CLI reporting | Internally computed scheduler work and retention were dropped by the API mapping. The final CLI exposes separate fields and the recorded core counters. The independent mapping review accepts the `query_before_disposal` scope; it does not claim failed-query or later cleanup snapshots. |
| Antihydra admission | A detached cache accepted submitted coefficients with a genuine key. Checking a temporary publication tuple was still insufficient. The final cache accepts only an admitted image handle and computes coefficients internally through the core projection and exact support. Tests reject incorrect coefficients even while the image is live. The independent review accepts this repaired path. |
| Antihydra storage | Full coefficient arrays in each intermediate image exceeded larger-lane budgets. Intermediate records now hold bounded leaf/prefix descriptors and parent handles. Contexts, images and seals are released after construction and on failure. |
| Antihydra performance | Cold projection still visits each return, and source revalidation remains linear. The same-run retained-fragment cache is useful but does not establish cheap new CLI queries, relative action transport or first-failure refinement. |
| 196 temporal image | Existing local codecs compose spatial maps. Context summaries admit original source cells, not recursive temporal images. The thirteen-channel temporal image, dynamic prior extent and image-level mirror transport remain unconstructed. This is not an impossibility proof derived from a smaller projection. |
| Collatz common image | Whole accelerated-event germs cannot directly represent every physical cut, including an initial even run or a target inside the final halving suffix. The total 1–4–2 orbit and event termination at one need distinct consumers of a common admitted support. The production bridge remains missing. |
| Fermat/Mersenne | The exact research multipoint evaluator avoids enumerating every progression leaf but still has window-scale polynomial storage/work exponential in candidate bit length. Neither that evaluator nor the semantic unit theorem supplies the required compact terminal construction. |
| Isabelle relevance | New prime arithmetic and finite-set lemmas are checked. Deterministic Python worklists, source admission, cache lifecycle, executable consumer refinement, macro contraction, other-family projections and the source-7 barrier remain separate obligations. |

The final prime constructor reviewer accepted the Antihydra cache repair and
the CLI metrics mapping after their corrections. The 196 explorer independently
mapped the missing temporal context-input contract and a candidate chronological
law, without claiming a construction bound. The proof reviewer kept the
finite arithmetic lemmas distinct from unproved executable refinement.

No independent all-family release sign-off is claimed. In particular, the
source-image core has not replaced all existing family executors or integrated
its images into the common leased process cache. Its scoped admission tests
cannot substitute for those missing constructions and proofs.
