## Implemented

- Wide radix spatial parents compose modular-affine remainder transfers and
  canonical activation thresholds without expanding the numeric domain into a
  Boolean truth DAG. Distinct outputs and remainder semantics remain distinct.
- Original-source affine queries reuse dyadic source summaries for prefix carry
  and shift observations instead of repeatedly scanning prefixes.
- Semantic construction reserves workspace and journals cross-store publication;
  cancellation releases staged data and closed transaction IDs reject reuse.
- Reverse current-growth summaries use the carry-reset monoid. Blank holes
  decline this optimization and use the existing causal evaluator.
- Atomic validity masks, total Boolean identities, and identity-bound midpoint
  functions avoid redundant decision-DAG reductions. Spatial parent compilation
  performs seven substitutions instead of nine. Duplicate spatial publication
  no longer inflates late-alias counts.
- Collatz regressions now verify the current tile application while poisoning
  retired execution paths. Exact oracle inputs and output assertions remain.
